# 项目里程碑

项目不是跟教程敲一遍。每个项目至少要有：README、运行命令、测试、失败案例、限制说明。

| 里程碑 | 周 | 最小要求 | 面试可讲点 | 状态 |
|---|---:|---|---|---|
| P1 日志清洗器 | 2 | 读 JSONL、清洗、统计、CLI、单测 | 边界、生成器、错误处理 | 未开始 |
| P2 LLM API 代理 | 4 | FastAPI、超时、重试、限流、日志 | 异步、失败恢复、成本 | 未开始 |
| P3 文档问答 | 6 | 切块、检索、引用、拒答 | RAG 失败分析、引用可信度 | 未开始 |
| P4 mini agent | 8 | 工具注册、循环、终止、状态 | 工具设计、死循环、上下文 | 未开始 |
| P5 eval harness | 10 | 20+ 用例、指标、回归报告 | 评测设计、judge 偏差 | 未开始 |
| P6 capstone | 13 | 部署、监控、降级、安全用例 | 系统设计、权衡、故障演练 | 未开始 |

## 项目 README 模板

```markdown
# 项目名

## 解决什么问题
## 架构 / 数据流
```
